## 🏗 Featured Project — Kyrion

### [Kyrion](https://github.com/flodinhooo/kyrion) — A Local-First Home Operating System

**One connected environment for devices, services, automations and optional AI.**

Kyrion is my ongoing project to bring fragmented smart-home and digital services together in a secure, extensible platform — with local control at its core.

- 🏠 **Smart home:** Device discovery, rooms and integrations including Zigbee, Nanoleaf and Philips Hue
- 🧠 **Local AI:** Ollama-powered chat and bounded, Core-validated action proposals
- 🎙️ **Velora:** Raspberry Pi voice satellite with local wake-word detection and speech transcription
- 🔐 **Security-first:** Authentication, role-based access control and auditable actions
- 🧩 **Modular architecture:** Independent web, Core, AI and hardware gateway components

**Built with:** Next.js · React · TypeScript · Kotlin · Spring Boot · Python · FastAPI · PostgreSQL · Raspberry Pi

> 🚧 Active development prototype — not yet a finished consumer product.
